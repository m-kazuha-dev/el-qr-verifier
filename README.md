# 地方税統一QRコード（eL-QR）電文解析・整合性検証ツール

地方税統一規格（JPQR / EMVCo準拠・MPN仕様）に基づいた255桁のQRコード電文をパースし、各種チェックディジット（モジュラス10/11、CRC-16）の整合性を瞬時に検証するWebアプリケーションです。

---

## 開発背景・解決した課題
* **業務背景**: 地方税の納税通知書・納付書に印字される eL-QR は、255桁の中に複数の規格（MPN、JPQR）と多重のチェックディジットを含んでいます。
* **課題**: 帳票レイアウト変更時や年次改修時のテストにおいて、電文の桁ズレやチェックディジット誤りが発生した際、手作業での逆算や目視確認では原因特定に多大な工数がかかっていました。
* **解決策**: 入力電文を即座に分解・パースし、仕様に基づいたチェックディジット（CD1, CD2, CD3）を自動再計算して一致判定を行う検証ツールを構築。検証作業の迅速化と人的ミスの防止を実現しました。

---

## 実務版との差異（ポートフォリオ公開にあたって）
本リポジトリは、コアとなる解析・検証ロジックを誰でも手軽に確認できるよう、Web（Blazor WebAssembly）向けにシンプルに再構成したポートフォリオ版です。実務で運用していた内部ツールとは以下の点が異なります。

* **入力インターフェース**:
  * 実務版：PC接続のWebカメラ・外部ライブラリ（OpenCV / ZXing等）を用いた帳票QRコードの直接スキャン読み込みに対応
  * 本ツール：環境依存を排除しブラウザ上で即座に検証できるよう、255桁電文のテキスト入力に特化
* **表示項目**:
  * 実務版：収納機関番号、税目・料金番号、税事務所コード、納期限、支払期限、案件特定キーなど帳票上の全メタデータを網羅的にマッピング表示
  * 本ツール：主要項目（納付額・納期限）およびコアとなる各種チェックディジットの検証結果にフォーカスして表示

---

## 主な機能
* **255桁電文のパース**: 納付額、納期限、課税年度などの主要フィールドを即座に分解抽出
* **MPNチェックディジット検証（CD1, CD2）**: モジュラス10/11および可変ウェイト乗算を用いた2桁CDの検証
* **JPQR / EMV準拠 CRC-16検証（CD3）**: 生成多項式 `0x1021`（CRC-16/CCITT-FALSE）による巡回冗長検査の検証

---

## 技術スタック・アーキテクチャ
* **フレームワーク**: .NET 8 / Blazor WebAssembly
* **言語**: C#
* **設計のポイント**:
  * **UIとドメインロジックの分離**: 計算・検証ロジック（`ElQrValidator`）を画面層から独立させ、単体テストや他プラットフォームへの移植が容易な構造に設計。
  * **WebAssemblyによる高速・安全なクライアント実行**: サーバー通信や外部送信を行わず、ブラウザ内のWebAssembly上でC#ロジックを直接実行。機密性のある税務電文の外部流出を防ぎます。

2. アプリケーションの起動
    ```bash
    dotnet watch
    ```
3. ブラウザでアクセス
    起動後、コンソールに表示されるローカルURL（例: http://localhost:5107 など）をブラウザで開いて利用します。
